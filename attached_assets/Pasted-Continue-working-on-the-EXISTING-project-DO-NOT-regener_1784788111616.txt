====================================================
3. NEW PATIENT FLOW
====================================================

This is the most important improvement.

Completely redesign the patient creation workflow.

Desired workflow:

User presses

NEW PATIENT

↓

Instead of immediately creating a patient, show a search field.

The receptionist starts typing:

first name
last name
phone number

While typing, search existing patients instantly.

If matching patients exist:

Show a beautiful modal/dialog.

Example:

Existing patient found

John Smith

555-123456

[Select Existing Patient]

[Create New Patient]

If the receptionist selects the existing patient:

Immediately continue to

NEW APPOINTMENT

with that patient already selected.

If no matching patient exists:

Continue creating a brand new patient.

After saving the patient,

automatically open

NEW APPOINTMENT

with that patient already selected.

The receptionist should never need to manually find the patient again.

This workflow should require as few taps as possible.
